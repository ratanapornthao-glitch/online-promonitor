# Real-data pilot: คู่มือเก็บ screenshot จริง

เป้าหมาย: วัดว่า Agent อ่าน **หน้าสินค้าจริง** ได้แม่นแค่ไหน เทียบกับข้อมูลจำลอง (100%) โดยใช้โครงเดียวกัน

> ข้อมูลจริงเก็บใน `data_real/` ซึ่งอยู่ใน `.gitignore` **จะไม่ขึ้น GitHub** ตอนรายงานผลให้เรียกแบรนด์เป็น Brand A–E

## 1. เลือกอะไรมาเก็บ

- **5 แบรนด์** สกินแคร์ที่มีร้าน official ครบ 3 แพลตฟอร์ม (Shopee Mall / LazMall / TikTok Shop Mall) มีทั้งแบรนด์ mass และ premium อย่างน้อย 1 แบรนด์
- **4 สินค้าต่อแบรนด์** ประเภทละ 1 ชิ้น:

  | sku-hint ในชื่อไฟล์ | ประเภท | ขนาดใกล้เคียง |
  | --- | --- | --- |
  | `sunscreen` | กันแดด | ~50 ml |
  | `serum` | เซรั่ม | ~30 ml |
  | `cleanser` | โฟมล้างหน้า | ~150 ml |
  | `moisturizer` | มอยส์เจอไรเซอร์ | ~50 g |

- ต้องเป็น **SKU เดียวกัน ขนาดเดียวกัน** ทั้ง 3 แพลตฟอร์ม (ขนาดไม่ต้องตรง 50/30/150 เป๊ะ แต่ต้องเท่ากันข้ามแพลตฟอร์ม)
- รวม 5 × 4 × 3 = **60 ภาพ** (ถ้าเวลาน้อย: 5 แบรนด์ × 2 สินค้า = 30 ภาพ)

## 2. วิธีแคป

- **1 listing = 1 ภาพ** ต้องเห็นครบในภาพเดียว: ชื่อสินค้า, ราคาขาย, ราคาเต็ม (ขีดฆ่า), โค้ดร้าน/โปรร้าน, voucher แพลตฟอร์ม
  - บนมือถือถ้าไม่พอหน้าจอ ใช้ "แคปยาว / scroll capture" ให้เป็นภาพเดียว
- แคปจาก **หน้าสินค้า** เท่านั้น ไม่ใช่ live, โฆษณา หรือลิงก์ affiliate
- แคป **ทุกภาพในวันเดียวกัน** ช่วงเวลาใกล้กัน (ราคาเปลี่ยนระหว่างวัน)
- **ครอปหรือปิด** ชื่อบัญชีผู้ใช้ ที่อยู่ แชท หรือข้อมูลส่วนตัวอื่น ๆ ออกก่อนบันทึก
- แคปด้วยมือในปริมาณน้อย ไม่ใช้ scraper (ตามข้อกำหนดของแพลตฟอร์ม)

## 3. ตั้งชื่อและวางไฟล์

```
data_real/screenshots/normal_2026-11-14/<brand>_<sku-hint>_<platform>_<YYYYMMDD>.png
```

- `<brand>`: ชื่อแบรนด์จริงแบบตัวอักษรภาษาอังกฤษติดกัน ไม่มีเว้นวรรค (เช่น ชื่อร้าน "Vela Skin" → `velaskin`) เพื่อให้ validator เทียบกับชื่อที่เห็นในภาพได้
- `<platform>`: `shopee` / `lazada` / `tiktok`
- `<YYYYMMDD>`: วันที่แคปจริง ถ้าไม่ใช่วันที่ 14 พ.ย. ให้เปลี่ยนชื่อโฟลเดอร์เป็น `normal_<วันที่>` ด้วย
- ถ้าเก็บช่วง Payday ด้วย: `data_real/screenshots/payday_2026-11/` (SKU ชุดเดิม)

## 4. กรอกเฉลย (ground truth)

copy `docs/ground_truth_template.csv` ไปเป็น `data_real/ground_truth.csv` แล้วกรอก **1 แถวต่อ 1 ภาพ** โดยดูจากภาพเอง:

| คอลัมน์ | กรอกอะไร |
| --- | --- |
| screenshot_file | ชื่อไฟล์ภาพ |
| campaign_name | ชื่อโฟลเดอร์ เช่น `normal_2026-11-14` |
| platform | shopee / lazada / tiktok |
| size_ml_g | ขนาดเป็นตัวเลข (ml หรือ g) |
| list_price | ราคาเต็มที่ขีดฆ่า (ไม่มีให้เว้นว่าง) |
| display_price | ราคาขายตัวใหญ่ ก่อนใช้โค้ด |
| shop_voucher_thb | โค้ด**ร้าน**ที่ใช้กับสินค้า 1 ชิ้นได้ (บาท) ไม่มีใส่ 0 |
| upsell_mechanic | `bundle` / `spend_x_save_y` / `multi_buy` / `gift_threshold` / `none` |
| min_spend_or_qty | ยอดหรือจำนวนขั้นต่ำของโปรอัพเซลล์ (ไม่มีเว้นว่าง) |
| notes | สิ่งที่ยาก เช่น "มีโค้ด 2 ใบ ไม่แน่ใจว่าใครออก" |

- คนกรอกเฉลย **ไม่ควรเป็นคนเดียวกับคนดูผล Agent** และควรกรอกก่อนรัน Agent
- voucher / coins / cashback ของแพลตฟอร์ม **ไม่นับ** เป็น shop_voucher

## 5. รัน

บอก Claude Code: "รัน blind test ข้อมูลจริงกับ normal_2026-11-14" ระบบจะอ่านภาพ → validate → วัดความแม่นยำ → สรุปจุดที่พลาด โดยเขียนผลทั้งหมดใน `data_real/output/` เท่านั้น
